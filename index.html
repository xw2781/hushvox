How it works

HushVox runs DeepFilterNet3, a small neural network designed for real-time speech enhancement, compiled to WebAssembly. When you add a file, your browser decodes it, converts it to 48 kHz, and feeds it through the model in a background thread, a couple of seconds at a time. The model estimates which parts of the spectrum are speech and which are noise, and attenuates the rest.

  1. Decode. Your browser’s built-in decoder reads the file; video files work if the browser can read their audio track.
  2. Enhance. The model processes each channel at 48 kHz. It has about 30 ms of built-in latency, which HushVox compensates so the result lines up sample-for-sample with the original.
  3. Compare and mix. Switch between original and enhanced at the same playhead position, and use the Strength slider to blend some of the original back in.
  4. Export. Download 16-bit WAV or MP3 at 48 kHz with the same channel count as the source.

Privacy

Your audio is decoded, processed and exported in your browser tab. There is no server-side component: this is a static site. The page makes no analytics calls and loads no third-party scripts, fonts or images, and its Content Security Policy only allows requests to its own origin. The only download is the model itself (about 12 MB compressed), which your browser keeps in its cache after the first use.

HushVox is a noise suppressor. It removes noise rather than re-creating a studio voice, so on very noisy input the result can sound slightly processed. We make no claim that it matches any particular commercial product.

FAQ

Which file formats work?

Anything your browser can decode: typically WAV, MP3, M4A/AAC, OGG/Opus, FLAC and WebM, plus the audio track of many MP4/MOV/WebM videos. If a file can’t be decoded, HushVox says so instead of failing silently. Exports are WAV (16-bit PCM) or MP3 (192 kbps).

How long can a file be?

There is no fixed limit, but the audio is held in memory as 32-bit floats at 48 kHz (roughly 0.7 GB per hour per channel, for the original plus the enhanced copy), so very long files may fail on phones or low-memory machines. Processing runs in chunks with a progress bar and a Cancel button. If you have a multi-hour recording, splitting it is the safer route.

Why 48 kHz?

DeepFilterNet3 was trained for 48 kHz audio, so files are resampled to 48 kHz before processing and exported at 48 kHz. Content above the original file’s bandwidth is not invented: a 16 kHz recording stays band-limited.

Is my audio uploaded anywhere?

No. All processing happens locally in your browser, and the page is built so that it cannot contact other servers. You can verify this in your browser’s network tools.

What are its limits?

It is a noise suppressor, not a magic studio-voice generator. It is built for speech: music and other non-speech sounds are treated as noise and are not preserved. Heavy noise, strong reverb, or several people talking at once can leave artifacts, and the voice may sound slightly processed. For already-clean recordings it will add little and may make things worse. Use the Strength slider or the Max noise reduction setting to dial it back.

Why does the first run download about 12 MB?

The neural network is embedded in a WebAssembly file (about 34 MB uncompressed, about 12 MB transferred with compression). It is fetched only when you first process a file and then cached by your browser, so later runs start immediately.
